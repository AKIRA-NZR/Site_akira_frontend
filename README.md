## ⚡ Visão Geral

Portfólio pessoal de **Deyvid Alves (AKIRA)**, construído com arquitetura **Islands (Zero-JS Waterfall)**, engenharia de cor perceptual **OKLCH**, átrio responsivo em tela cheia e pipeline automatizado de otimização de mídia (**Sharp AVIF/WebP** + **FFmpeg Faststart**).

---

## 🛠️ Stack do Projeto

- **Framework:** [Astro 5+](https://astro.build/) (Static Site Generation / Islands Architecture)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS v4](https://tailwindcss.com/) + CSS Defensivo (`OKLCH`) + LightningCSS
- **Animações & Micro-interações:** [Motion One](https://motion.dev/) (`stagger` + Spotlight Óptico)
- **Ícones Vetoriais:** `astro-icon` (`Simple Icons` & `Devicon`)
- **Pipeline de Mídia:** `sharp` (AVIF/WebP responsivos) + `ffmpeg` (H.264 CRF 28 `+faststart`)

---

## 🚀 Como Executar Localmente

```bash
# 1. Instalar dependências
npm install

# 2. Rodar servidor de desenvolvimento (http://localhost:4321)
npm run dev

# 3. Gerar build estático otimizado de produção (pasta dist/)
npm run build

# 4. Visualizar build de produção localmente
npm run preview
```
